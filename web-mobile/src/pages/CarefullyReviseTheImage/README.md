# 改图模式功能页面

## 功能概述

这是一个图像编辑和处理页面，提供多种AI辅助的图像修改功能。用户可以上传图片，并通过
一键渲染，局部重绘，智能清除，高清放大，一键抠图，万物迁移
模式对图片进行精细修改和处理。

## 主要功能

1. **一键渲染**：用户可以选择场景、风格模型和提示词，对上传的图片进行一键式渲染处理。

2. **局部重绘**：允许用户选择图片的特定区域进行重绘，可以保持原有风格或使用自定义风格。

3. **智能清除**：提供智能清除图片中不需要的元素的功能。

4. **高清放大**：提供图片高清放大功能，用户可以清晰地查看和编辑图片细节。

5. **一键抠图**：允许用户一键抠出图片中的主体部分，方便后续的编辑和合成。

6. **万物迁移**：可能是一种将图片中的元素迁移到其他场景或风格的功能。


## 组件结构

- `FunctionGroup`：功能模式选择组件
- `UploadBaseImages`：图片上传组件，支持进度，历史创作选择，SU插件时可进行快速截图上传
- `ChoseScene`：场景选择组件，后端会返回一颗场景tree
- `StyleSetting`：风格设置组件，支持风格模型选择，通过预训练的特征得到一致性的出图效果
- `PromptSetting`：提示词设置组件，不支持随机提示词，不支持上传图片生成提示词
- `ReDrawStyle`：重绘风格设置组件，暂无作用
- `MaskLayerDraw`：遮罩层绘制组件，用于局部重绘，智能清除和万物迁移时进行选区蒙层绘制，该部分较复杂，将有组件readme说明
